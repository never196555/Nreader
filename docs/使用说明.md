# Nreader 使用说明

一个轻量的桌面小说阅读小窗口：无标题栏、显示行数自动填满窗口、翻页按键可自定义、阅读进度自动记忆。

---

## 〇、先选模式：exe 版 还是 Python 版？

包里有两种运行方式，功能完全相同，**共用同一个 novels 小说目录和同一份阅读进度**，随时可以换着用：

| 对比项 | 模式1：exe 免安装版 | 模式2：Python 源码版 |
|--------|--------------------|--------------------|
| 对应文件 | `Nreader.exe` | `novel_reader.pyw` + `Start-Python-Mode.bat` + `Install-Python.txt`（安装指引） |
| 需要安装 | 什么都不用装 | 需要安装一次 Python（免费，约 2 分钟） |
| 启动方式 | 直接双击 exe | 双击 .pyw 或双击启动器 .bat |
| 适合场景 | 绝大多数 Windows 电脑 | 电脑限制/打不开 exe、exe 被杀软拦截或删除 |

**建议：先试模式1**（最省事）；如果 exe 打不开或被拦截，再用模式2。

---

## 一、模式1：exe 免安装版

1. 把整个"Nreader"文件夹解压/复制到任意位置（推荐 D 盘等非系统目录；**不要放 C:\Program Files**，否则可能没有写入权限，进度存不了）
2. 双击 `Nreader.exe` 即可开始阅读
3. 若首次运行弹出"Windows 已保护你的电脑"（SmartScreen 蓝色提示）：点左下角 **更多信息 → 仍要运行**（exe 未经数字签名，属正常提示）
4. 若被杀软拦截或删除：把 exe 加入信任名单，或直接改用模式2

## 二、模式2：Python 源码版（exe 打不开时用）

### 第一步：安装 Python（只需一次，已装过可跳过）

1. 打开官网下载页面：**https://www.python.org/downloads/**
2. 运行下载的安装包，**务必勾选安装窗口底部的 "Add python.exe to PATH"**（关键步骤，漏掉会导致找不到 Python）
3. 点击 **Install Now**，等待安装完成即可

> 本程序主体只用到 Python 自带的标准库（tkinter），**无需安装任何第三方库**即可阅读；仅 Python 版导入 PDF、MOBI/AZW3 格式时需额外执行一次 `python -m pip install pypdf mobi`（exe 版已自带，无需此步）。

### 第二步：启动阅读器

- **方式 A**：双击 `novel_reader.pyw` —— 直接启动，无黑窗（安装 Python 后系统会自动关联 .pyw）
- **方式 B**：双击 `Start-Python-Mode.bat` —— 自动检测环境；若未安装 Python，会自动打开中文安装指引 `Install-Python.txt`

## 三、翻页方式

三种方式同时可用：

| 方式 | 操作 | 生效范围 |
|------|------|----------|
| 鼠标点击 | 左键 = 下一页，右键 = 上一页（可在设置中分别开关） | 鼠标在显示框内 |
| 鼠标滚轮 | 向下 = 下一页，向上 = 上一页 | 鼠标在显示框内 |
| 键盘 | 上一页 ↑、下一页 ↓（默认，可在设置中自定义更多按键） | **仅本窗口**（先单击选中阅读窗口） |

> 键盘翻页只在本窗口被选中（单击）时生效，且此时这些按键会被工具**完全接管**——不会漏到浏览器等其它程序（比如按方向键翻页时，浏览器的光标不会跟着动）。点击其它程序后，按键即恢复正常输入，互不干扰。
> 翻页按键支持自定义：F1 → 设置 → "上一页按键 / 下一页按键"，可多选预设键（↑/PgUp/W/K、↓/PgDn/S/J/空格），也可点"录制"绑定任意按键。默认 = 上一页↑、下一页↓。
> 背景无底色（全透明）模式下，框内任意位置的单击、右击、滚轮都会被接管为翻页操作。

## 四、窗口操作

- **移动窗口**：按住框内任意位置拖动
- **调整大小**：拖动窗口边缘或四角（距边缘约 6 像素内），光标会变为双向箭头
- **最小化（隐藏窗口）**：按 **Ctrl+Shift+M**（默认，可在设置中改）一键隐藏（任何情况下都生效，可当"老板键"用），再按一次即唤回；**双击任务栏图标或双击托盘（后台）图标**同样在最小化/显示之间切换；也可用托盘右键菜单"最小化（隐藏）"。不想让窗口一直挂在桌面上时用它
- 显示行数根据窗口高度**自动计算并填满**，无需手动设置行数
- 窗口大小、位置会自动记忆

## 五、设置界面（按 F1 打开）

| 配置项 | 说明 |
|--------|------|
| 字体 | 下拉选择系统安装的字体 |
| 字号 | 8 – 60 |
| 字体颜色 | 点击色块打开调色板自选颜色 |
| 背景无底色 | 勾选后背景完全透明，屏幕上只显示文字（详见第六节） |
| 整体透明度 | 0.2 – 1.0，控制整个窗口的透明程度 |
| 窗口置顶 | 是否悬浮在其它窗口之上 |
| 关闭快捷键 | 自定义格式如 `Ctrl+Shift+Q`、`Alt+F2`，须含 Ctrl/Alt/Shift 之一（本窗口选中时生效） |
| 最小化快捷键 | 自定义隐藏/唤回窗口的热键（默认 `Ctrl+Shift+M`，**全局生效**，格式同上；不能与关闭快捷键相同） |
| 上一页按键 | 多选预设（↑/PgUp/W/K）+ "录制"自定义任意按键 |
| 下一页按键 | 多选预设（↓/PgDn/S/J/空格）+ "录制"自定义任意按键 |
| 鼠标单击翻页 | 左键=下一页、右键=上一页，可分别勾选开关 |
| 任务栏图标 | 勾选后任务栏出现本工具按钮，点击唤出窗口、**双击在最小化/显示间切换**（默认不勾选，详见第六节） |
| 托盘图标（后台图标） | 勾选后系统托盘（右下角）出现本工具图标，单击=显示窗口，**双击=最小化/显示切换**，右键=菜单（显示窗口/最小化/打开设置/退出）（**默认勾选**） |
| ♥ 打赏支持 | 设置界面右下角按钮，弹出收款码窗口（详见第十节） |
| 当前文件 | 下拉切换 novels 目录中的不同小说（导入后统一存为 TXT） |
| 导入小说 | 选择 TXT/EPUB/MOBI/AZW3/PRC/PDF/DOCX/HTML 文件，自动提取正文转成 TXT 存入 novels 目录并打开 |

窗口尺寸无需输入数字，直接拖动窗口边缘即可。

默认外观：宋体 10 号、白色文字、背景无底色、整体透明度 0.81、窗口置顶、翻页按键 ↑/↓；默认窗口约 15 个 10 号字宽、每页 3 行（可拖动边缘自由调整）；默认显示托盘图标（后台图标）。

## 六、背景无底色（全透明）模式说明

- 勾选后背景完全消失，文字浮在其它窗口上方，适合叠加阅读
- 系统特性：透明区域的鼠标操作会**穿透**到下层窗口，因此本程序用全局鼠标钩子接管了框内交互——拖动、缩放、点击翻页、滚轮翻页在框内任意位置都可用；**框外完全不干预**
- **鼠标移到窗口边缘约 6 像素范围内时，边框会自动显形**（淡蓝色高亮条），提示可抓取的位置；移开后自动恢复透明
- 抓住显形的边框（或任意边缘/四角）拖动即可调整大小；显形时鼠标也会显示双向箭头
- 文字半透明效果通过"整体透明度"调节
- 想恢复深色文本底框时，取消勾选即可

### 图标入口（任务栏 / 托盘）——解决"窗口被挡住找不回来"

- 未置顶时其它窗口会盖住阅读窗口，没有图标就无处可点。可在设置中勾选**任务栏图标**和/或**托盘图标（后台图标）**，两个独立勾选，勾哪个哪个出现，都勾则两处都有；都不勾则完全无图标。**托盘图标默认已勾选**，任务栏图标默认不勾
- **任务栏图标**：任务栏出现本工具按钮，点击按钮唤到最前，**双击按钮 = 最小化/显示切换**
- **托盘图标**：屏幕右下角系统托盘出现本工具图标——**单击 = 显示窗口**（唤到最前），**双击 = 最小化/显示切换**，**右键 = 菜单**（显示窗口 / 最小化 / 打开设置 / 退出）
- 建议不勾"窗口置顶"的用户至少开启一个图标，方便随时找回窗口
- **最小化/隐藏**：Ctrl+Shift+M（默认，可在设置中改；全局热键，任何时候按都生效）或托盘右键菜单"最小化（隐藏）"；隐藏后窗口完全消失，再按一次热键或点托盘图标即恢复

## 七、导入与切换小说

- 目录：软件文件夹下的 `novels` 文件夹（首次运行自动创建）
- **随包附带 `使用说明.txt`**：首次运行（还没选过小说时）窗口里会直接显示这份说明，即使误关了设置界面也能随时看到怎么操作；用"当前文件"下拉可随时切回
- 导入方式：设置里点"导入小说"，或直接把 `.txt` 文件拷进该文件夹
- **支持格式**：TXT、EPUB、MOBI/AZW3/PRC（Kindle）、PDF、DOCX（Word）、HTML/HTM；非 TXT 格式导入时自动提取正文并转成纯文本 TXT（原文件不动），之后和普通 TXT 一样阅读
- 注意：扫描版 PDF（整页图片、没有文字层）提取不到文字；加密 PDF 无法解析；转换后的 TXT 位于 novels 目录，可自行删改
- 切换：设置里"当前文件"下拉选择，切换时各文件进度**分别记忆**
- 支持编码：UTF-8、GBK/GB18030、Big5、UTF-16 等，乱码文件也能尝试打开
- **两种模式共用此目录**：用 exe 导入的小说，切到 Python 版同样能看

## 八、阅读进度记忆（防丢进度）

- **每次翻页立即将进度写入磁盘**（软件文件夹下的 `reader_config.json`），闪退、强制结束进程、断电关机都不会丢失
- 重新打开时自动定位到上次阅读的位置
- **两种模式共用同一份进度**：换模式打开会接着上次的位置看
- 若文件被替换或修改，会按字符偏移智能定位并做边界保护

## 九、常见问题

**Q：exe 打不开、闪退，或者被杀软删了？**
改用模式2（Python 源码版）即可，功能完全一样；也可以把 exe 加入杀软信任名单后再用模式1。

**Q：双击 novel_reader.pyw 弹出"选择打开方式"？**
说明 Python 还没装好。双击 `Start-Python-Mode.bat` 会自动打开安装指引（Install-Python.txt，内含下载地址和图文步骤）；装好 Python 后 .pyw 会自动关联，之后双击即可直接启动。

**Q：安装 Python 时忘记勾选 "Add python.exe to PATH" 怎么办？**
重新运行 Python 安装包，选 **Modify**，下一步时把 "Add python.exe to PATH" 勾上；或卸载后重装（这次务必勾选）。

**Q：两种模式可以混用吗？**
可以。exe 和 Python 版共用同一个 novels 文件夹和同一份阅读进度，随便换着用。

**Q：窗口没有标题栏，怎么关闭？**
Ctrl+Shift+Q（默认，可在设置中改）。设置窗口打开时该快捷键同样有效；设置窗口内按 Esc 或 F1 可只关闭设置。

**Q：方向键在别的程序里也会翻页？**
不会。键盘翻页只在阅读窗口被选中时生效；先单击一下阅读窗口再按方向键即可。

**Q：点击阅读窗口没反应？**
两种可能：一是该位置被其它窗口盖住了（此时点击会正常交给上面的窗口，属预期行为）；二是没点在窗口范围内。把窗口移到无遮挡处，或直接用键盘翻页（先单击选中窗口）。

**Q：窗口被其它窗口挡住了找不回来？**
右下角托盘图标（默认显示）左键点击即可唤出；也可按 F1 进设置勾选"任务栏图标"（详见第六节"图标入口"）。

**Q：想把窗口藏起来不想让它一直显示在桌面？**
按 Ctrl+Shift+M 一键隐藏（全局生效，可在设置中改成其它快捷键），再按一次即唤回；或托盘图标右键 →"最小化（隐藏）"。

**Q：配置会改坏吗？**
配置采用原子写入，写一半断电也不会损坏；异常时自动回退默认值。
